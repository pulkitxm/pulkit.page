An OpenAI Codex hackathon at Masters' Union. My teammates and I built Warden, which makes `npm install` less of a blind trust fall: it diffs a package against its last trusted release, runs deterministic malware heuristics, and asks an LLM to flag anything that still looks off. We placed 7th.
