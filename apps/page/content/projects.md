Things I've built, mostly open source. Each one links to its repository.

- **[edith](https://github.com/pulkitxm/edith)** - A native macOS control center for agent usage, remote machines, productivity tools, and private memory.
- **[claude-directory](https://github.com/pulkitxm/claude-directory)** - A growing library of open-source interface experiments: hero sections, GLSL shaders, design systems, animations, 3D components, and landing pages in React, Tailwind, and Three.js.
- **[x-chat-exporter](https://github.com/pulkitxm/x-chat-exporter)** - A one-click browser extension that exports an X conversation to a pixel-faithful offline HTML page with all its media bundled.
- **[kaksha](https://github.com/pulkitxm/kaksha)** - A class timetable manager for schools, actually used at an Indian government school.
- **[ac](https://github.com/pulkitxm/ac)** - A project runner for Apple Container on macOS, with declarative JSON stacks, readiness gating, and strict daemon ownership.
- **[warden](https://github.com/pulkitxm/warden)** - A trust layer that checks packages and agent diffs before they run.
- **[quinjet](https://github.com/pulkitxm/quinjet)** - Keyboard-first Git source control for the terminal, with syntax-highlighted diffs, commit history, staging, and live refresh, written in Rust.
- **[apfs-unlock-linux](https://github.com/pulkitxm/apfs-unlock-linux)** - Unlocks a hardware-encrypted SanDisk or WD drive on Linux and mounts its APFS volume automatically on plug-in.
- **[orbit](https://github.com/Noveum/orbit)** - A free, open-source, realtime task manager. Issues, boards, sprints, projects, and docs that sync instantly, keyboard-first and self-hostable.
- **[hinge](https://github.com/Noveum/hinge)** - Your MacBook desktop follows your lid.
- **[crowdflow](https://github.com/pulkitxm/crowdflow)** - Simulates crowd movement through a venue, spots bottlenecks before they form, and reroutes people in real time.
- **[fable-is-back](https://github.com/pulkitxm/fable-is-back)** - A Remotion recreation of a split-flap announcement animation, with sprites and motion extracted frame by frame.
- **[fabry.vercel.app](https://github.com/pulkitxm/fabry.vercel.app)** - An educational hub on Fabry disease, built with plain HTML and CSS. No frameworks, no build step.
- **[pulkit.page](https://github.com/pulkitxm/pulkit.page)** - The Bun and Turborepo monorepo that turns Markdown into this site and [pulkit.blog](https://pulkit.blog/).

More of my work lives on [GitHub](https://github.com/Pulkitxm).
